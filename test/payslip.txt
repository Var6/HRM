# Payslip Generator - Integration Guide

A production-ready payslip generator for Citizen Co-operative Society using React PDF Renderer.

## 📦 Installation

```bash
npm install @react-pdf/renderer
npm install jszip  # Optional: for bulk download feature
```

## 📁 File Structure

Place these files in your project:

```ini
lib/
├── PayslipDocument.tsx      # Main PDF component
├── payslip-utils.ts         # Helper functions
└── PayslipGenerator.tsx     # React UI component
```

## 🚀 Quick Start

### 1. Basic Usage - Download Button

```tsx
import { downloadPayslip } from '@/lib/payslip-utils';

const MyComponent = () => {
  const employee = {
    employeeId: 'EMP001',
    employeeName: 'ALAKA KUMARI',
    department: 'HR',
    designation: 'Dy. Manager-HR',
    // ... other fields
  };

  const handleDownload = async () => {
    await downloadPayslip(employee, 'January', '2026');
  };

  return (
    <button onClick={handleDownload}>
      Download Payslip
    </button>
  );
};
```

### Backend API Example (Node.js/Next.js)

```typescript
// app/api/send-payslip-email/route.ts
import { NextResponse } from 'next/server';
import nodemailer from 'nodemailer';

export async function POST(request: Request) {
  const { email, employeeName, month, year, pdfBase64 } = await request.json();

  // Configure your email transport
  const transporter = nodemailer.createTransport({
    host: process.env.SMTP_HOST,
    port: parseInt(process.env.SMTP_PORT || '587'),
    secure: false,
    auth: {
      user: process.env.SMTP_USER,
      pass: process.env.SMTP_PASS,
    },
  });

  // Send email with PDF attachment
  await transporter.sendMail({
    from: process.env.SMTP_FROM,
    to: email,
    subject: `Payslip for ${month} ${year}`,
    html: `
      <p>Dear ${employeeName},</p>
      <p>Please find attached your payslip for ${month} ${year}.</p>
      <p>Best regards,<br/>HR Department</p>
    `,
    attachments: [
      {
        filename: `Payslip_${month}_${year}.pdf`,
        content: pdfBase64,
        encoding: 'base64',
      },
    ],
  });

  return NextResponse.json({ success: true });
}
```

## 🐛 Troubleshooting

### PDF not rendering?

- Make sure `@react-pdf/renderer` is installed correctly
- Check that all required employee data fields are populated
- Verify date formats are valid

### Download not working?

- Check browser console for errors
- Ensure pop-ups are not blocked
- Verify all numeric fields are numbers, not strings

### Styling issues?

- @react-pdf/renderer uses its own styling system (similar to React Native)
- Standard CSS won't work - use the StyleSheet.create() API
- Flexbox is supported but has limitations

## 🚀 Performance Tips

1. **Lazy Loading**: Load PDFViewer only when needed

```tsx
import dynamic from 'next/dynamic';
const PDFViewer = dynamic(
  () => import('@react-pdf/renderer').then((mod) => mod.PDFViewer),
  { ssr: false }
);
```

2. **Caching**: Cache generated PDFs if they won't change
3. **Batch Processing**: Use `downloadBulkPayslips` for multiple employees
